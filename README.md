## 1. Nama dan Tujuan Proyek
* **Nama Proyek**: Portofolio Profesional Interaktif & Dashboard Analisis Data (*Neo-Brutalist Portfolio System*).
* **Tujuan Proyek**: 
  - Membangun personal branding digital yang kredibel dengan memadukan keahlian teknis analisis data (Python, SQL, Tableau) dan pengalaman operasional.
  - Menyajikan studi kasus visualisasi data nyata (seperti Analisis Kesiapan Digital Sekolah / IKDS menggunakan metode AHP dan data BPS) yang interaktif bagi rekruter dan stakeholder industri.

## 2. Sasaran Pengguna (*Target Audience*)
* **Recruiter & Talent Acquisition**: Tim HR dan manajer teknis di bidang teknologi, manufaktur, atau korporat yang mencari profesional dengan kombinasi ketrampilan data dan kedisiplinan operasional.
* **Akademisi & Penilai**: Dosen pengampu mata kuliah untuk keperluan evaluasi standar struktur pengumpulan tugas dan portofolio berbasis web.
* **Klien / Kolaborator**: Pihak yang membutuhkan konsultasi visualisasi data interaktif, perancangan antarmuka (UI/UX), maupun pengembangan web skala menengah.

## 3. Daftar Halaman dan Fitur
Portofolio ini dirancang dengan pendekatan *single-page application* / multi-section bergaya *neo-brutalist* yang responsif:
* **Beranda / Hero Section**: Menampilkan perkenalan singkat, identitas profesional (`aimartrophy.data`), serta tautan kontak cepat.
* **Tentang Saya (`/tentang`)**: Narasi latar belakang profesional, ringkasan pengalaman lintas industri, dan galeri personal kreatif (`STAGE_LIFE.RAW`).
* **Pengalaman (`/pengalaman`)**: Rekam jejak profesional mencakup pengalaman operasional dan manajerial.
* **Keahlian (`/keahlian`)**: Daftar *stack* teknologi (Python, SQL, Excel, Tableau, Laravel, Figma, Docker, n8n).
* **Proyek & Spotlight (`/proyek`)**: Menampilkan proyek unggulan seperti **INSPIRE Bigbang Data Viz Competition** (Juara 3 Nasional) lengkap dengan metrik utama dan pratinjau interaktif.
* **Kontak & Formulir Interaktif (`/kontak`)**: Saluran komunikasi langsung melalui email dan WhatsApp dengan validasi modal dwibahasa (ID/EN).

## 7. Cara Menjalankan Halaman Web (Lokal)
Jika Anda ingin menjalankan kode sumber ini secara lokal di komputer Anda:
1. Pastikan perangkat Anda memiliki browser modern (Google Chrome, Firefox, atau Edge).
2. Unduh atau *clone* repositori ini.
3. Masuk ke dalam direktori `source-code/`.
4. Buka file **`index.html`** langsung menggunakan browser pilihan Anda, atau gunakan ekstensi **Live Server** di Visual Studio Code untuk pengalaman pengembangan yang optimal.
